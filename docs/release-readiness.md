# DriveCoach 통합 상태

## 한 번의 연수 흐름

1. 홈에서 정차 제어 또는 차로 변경을 고른다.
2. 정차는 속도 시나리오를 재생한다. 차로 변경은 좌우 방향과 교통 상황을 고른 뒤 직접 깜빡이를 조작하고 대기 여부를 선택한다.
3. 결과에 실제로 관찰된 항목과 복기할 점을 표시한다. 간격이 이미 확인된 장면에서도 추가로 기다리는 선택은 안전 목표를 충족한다.
4. 홈의 다음 연습 카드를 통해 필요한 과제로 돌아간다. 휴대폰 모의 연수에서 완료한 기록은 최근 24회까지 불러올 수 있다.

정차 요약은 표본이 가장 많은 단일 접근 속도대를 기록한다. 차로 변경은 관찰한 항목의 개수와 기준을 충족한 개수를 기록한다. 정차와 차로 변경을 하나의 운전자 점수로 합산하지 않는다.

## 데이터와 차량 상태

- 휴대폰의 기록에는 연수 종류, 완료 시각, 관찰과 충족 횟수, 다음 연습 항목만 저장한다. 앱 전용 백업 제외 영역에 저장하고, 홈에서 기록을 지울 수 있다.
- 모의 연수의 단계와 선택은 일반 Android 화면이 재생성돼도 복원할 수 있다. 정차 재생은 앱 화면이 중단되면 일시 정지된다. 완료 기록은 결과 화면의 재구성 과정에서 다시 작성되지 않는다.
- Pleos 디버그 빌드는 표준 AAOS `GEAR_SELECTION`의 P 상태와 `CarUxRestrictions`의 확인된 조작 허용을 함께 요구한다. 둘 중 하나가 해제되거나 확인할 수 없으면 모의 연수 화면을 닫는다. 화면이 중단되면 주차 모의 연수의 요약도 사라진다. 주차 권한 선언은 `app/src/debug/AndroidManifest.xml`에 둔다.
- 실제 속도 연수는 최근 수신한 `PERF_VEHICLE_SPEED` 이벤트가 있어야 시작할 수 있다. 신호가 끊기거나 앱이 중단된 세션에는 평가 보류를 표시한다.
- 현재 차로 변경은 모의 입력을 사용한다. 실차에는 승인된 방향지시등 신호와 독립적으로 확인한 차로 변경 시작·완료 기록이 필요하다.

## Pleos에서 확인할 순서

| 범위 | 확인할 내용 |
| --- | --- |
| 주차 UX | 지원되는 Pleos 이미지에서 P와 조작 허용을 확인하고 모의 연수를 연다. P 해제, 규제 변경, 서비스 연결 해제 시 상세 화면과 연수 조작이 닫히는지 본다. |
| 기본 연수 | 정차 3개 시나리오와 차로 변경 3개 상황을 실행해 결과, 다음 연습, 뒤로 가기와 화면 복원을 확인한다. |
| 디자인 | 가로·세로 분할 창, 주야간 모드와 글자 확대에서 버튼과 결과 문구가 잘리는지 확인한다. |
| 신호 권한 | 대상 차종과 앱 카테고리의 접근 범위를 확인한다. 실차 주차 기능에 기어 권한을 추가할 때 배포 권한 범위를 다시 확인한다. |
| 제출 | 앱 카테고리, 아이콘, 스크린샷, 권한과 데이터 처리 설명을 확정한 뒤 App Market 등록 자료를 준비한다. |

현재 단계는 코드 통합이다. 새 버전의 빌드, 자동 테스트, Pleos 에뮬레이터와 실차 실행 확인은 보류 상태다.
