# DriveCoach · DriveAssistant

운전 초보자가 같은 상황을 반복해 보고, 다음 연습에서 바꿀 행동을 고르는 Pleos Connect 운전 연수 앱이다.

## 앱에서 연습하기

- **정차 제어**에서는 부드러운 감속, 급한 감속, 반복 정차 중 하나를 재생한다. 결과는 비슷한 접근 속도에서 관찰한 정차 횟수와 강한 감속 후보를 보여 준다.
- **차로 변경**에서는 왼쪽이나 오른쪽을 골라 미리 신호를 켜고, 이동 중 유지하고, 완료 후 끈다. 옆 차로의 뒤차 접근, 시야 가림, 간격 확인 상황에서 각각 이동할지 기다릴지 선택한다.
- **다음 연습**은 직전 결과에 따라 안전 간격, 신호 타이밍, 신호 유지, 소등 또는 정차 복기를 안내한다.

| 환경 | 사용할 수 있는 기능 |
| --- | --- |
| 일반 Android | 두 모의 연수와 최근 24회 기록. 결과 요약은 이 기기에 저장되며 앱에서 지울 수 있다. |
| Pleos 디버그 빌드 | 기어 P와 `CarUxRestrictions`의 조작 허용이 모두 확인되면 두 모의 연수를 연다. 주차 연수를 닫으면 그 기록은 사라진다. |
| Pleos 차량 연동 | 권한과 속도 신호를 확인해 차량 속도 기반 정차를 관찰한다. 앱 중단이나 신호 결손이 있는 연수는 평가를 보류한다. |

모의 연수는 외부 센서나 네트워크 없이 실행한다. 차량 속도 기록은 권한을 허용한 상태에서 공식 AAOS 속도 프로퍼티를 사용한다. Pleos 디버그 빌드에서만 주차 확인용 기어 읽기 권한을 선언한다.
